Session defaults

HEAD uses the project’s current commit. Uncommitted changes are not copied. Existing sessions keep their choices.

Tools

A name, the first command submitted to your shell, and an optional continue command.

Shell is always available and submits no command. Commands use your interactive shell’s syntax and can include model flags or wrappers. Continue in new terminal submits the continue command once. Write {prompt} once, without quotes, where the tool accepts its first prompt, for example codex {prompt}. BonBon quotes the handoff prompt. Without a continue command, BonBon starts the tool with its normal command and does not send the prompt.
