BonBon 0.0.2 removes the installer dependency on GitHub CLI. The installer uses curl
and the tools included with macOS to select, verify, and install a prebuilt binary.
The BonBon runtime is unchanged apart from the version string.

## Install

Install with one command:

```sh
curl -fsSL https://github.com/gyson/bonbon/releases/latest/download/install.sh | sh
```

The installer selects Apple Silicon or Intel, verifies the archive's SHA-256,
checks the executable version, and installs to `~/.local/bin`. Add that directory
to PATH if needed, or use an absolute `--dir` for another installation directory.
Then run `bonbon server start` and `bonbon ui`.

## Updates

Rerun the install command to upgrade. Append `-s -- --check` after `sh` to check
for updates without changing the installed executable. `--version 0.0.2` selects
this release explicitly. Installation does not stop a running server; restart
with `bonbon server restart` when ready. Restart ends active sessions.

## Scope and validation

- macOS Apple Silicon and Intel packages; no Go, Node.js, jq, or GitHub CLI needed.
- Public and token-authenticated download paths use the same GitHub release API.
- Existing installer tests retain checksum, version, architecture, symlink, and
  atomic replacement coverage. Additional fixtures check anonymous requests,
  malformed metadata, and token handling without exposing it in process arguments.
- The release workflow requires tests and compiled-binary smoke checks on native
  Apple Silicon and Intel runners before publication.
- Binaries are not Apple Developer ID signed or notarized. No automatic update or
  background update check is added. Production data remains in `~/.bonbon`.
- The already published `v0.0.1` assets remain unchanged.
