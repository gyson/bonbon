BonBon 0.0.3 lets every browser tab type in a session and keeps message drafts in sync
across tabs. It adds a list of sent messages, an address for each view, and session
names in browser tab titles. The database format does not change.

## Included

- Type, paste, press Ctrl+C, and use Send from any browser tab that shows a session. The
  Take control step is removed. The terminal uses the size of the tab that most recently
  sent input.
- Edit a message in one tab, and the other tabs of that session show the edit. Send
  from one tab clears the message editor in all tabs. Another tab cannot send the same
  message again.
- Click **Sent messages** in the message editor to see the messages that Send sent in
  the session. Click **Copy** to put a message on the clipboard for use in another
  session.
  The list also includes messages that were sent before this release.
- Each message in the list shows **Sent** or **Not confirmed**. **Sent** means that the
  terminal write was confirmed. It does not mean that the agent accepted the message.
- Each view has its own address: `/` for the home page, `/sessions/<id>` for a session
  or draft, and `/settings` for Settings. A reload or bookmark opens the same view.
- The browser tab title shows the session or draft name. Click the BonBon logo to go to
  the home page.
- Sessions with the same time show in creation order, newest first. Before this release,
  their order was random.
- The release uses Go 1.27.3. `govulncheck` reported 9 reachable Go standard library
  vulnerabilities in the v0.0.2 executable, mostly in `net/http`. It reports none in
  this release.

## Upgrade from v0.0.2

```sh
bonbon update
```

The update replaces the executable while existing servers and sessions continue. When
ready, run:

```sh
bonbon server restart
bonbon ui
```

Restart ends active sessions. Then use the new UI at its new URL. Close BonBon tabs from
v0.0.2. They use protocol `bonbon/15` and cannot connect to the new server.

This release keeps SQLite format 6, so a v0.0.2 database needs no migration. Databases
from v0.0.1 (formats 3–5) still upgrade automatically at startup. Database downgrades
are not supported.

Old `/#<id>` addresses now open the home page, not the session. Select the session in
the sidebar, then bookmark its new address.

## Install

Install with one command:

```sh
curl -fsSL https://github.com/gyson/bonbon/releases/latest/download/install.sh | sh
```

The installer selects Apple Silicon or Intel. It verifies SHA-256 and the executable
version. It installs to `~/.local/bin`. If needed, add that directory to PATH. Use
installer `--version 0.0.3` to select this release explicitly. Then run
`bonbon server start` and `bonbon ui`.

## Scope and limits

- macOS Apple Silicon and Intel archives, plus `install.sh` and `checksums.txt`.
  Installed binaries need neither Go, Node.js, nor GitHub CLI.
- Built with Go 1.27.3 and `CGO_ENABLED=0`. Source builds now require Go 1.27.3 or
  later. Archives and the standalone executable include the project license and
  dependency notices.
- Production data remains in `~/.bonbon`, separate from `~/.bonbon-dev`. This release
  uses SQLite format 6 and protocol `bonbon/17`.
- Input from two tabs at the same time can interleave. Terminal focus and mouse reports
  are input too, so they also change the terminal size.
- Tabs sync the whole draft after the 400 ms save delay. The latest save wins. There is
  no character-level merge. Earlier draft revisions stay in history.
- **Sent messages** does not list text typed directly in the terminal. **Copy** copies
  only the text, not attachments or file paths.
- Native agent resume, conversation forks, imports, and backup/restore remain
  unavailable. Terminal recordings do not restore a process or hidden model state.
- Linux and Windows packages, background updates, and Apple Developer ID
  signing/notarization are not included.

## Validation

- Local checks with Go 1.27.3: `make test`, `make check`, `make web-check`, and
  `go test -race ./...`. `govulncheck` found no known vulnerabilities in the source or
  the release executable.
- Automated tests cover the size owner, draft sync and rejected saves, sent message
  pages and status, view addresses, and the session order for equal times.
- A compiled release smoke check uses a temporary instance to verify version reporting,
  the embedded UI and license notices, read-only SQL, and clean shutdown.
- Both archives match `checksums.txt`. Each archive contains the executable, `LICENSE`,
  and `THIRD_PARTY_NOTICES.txt`. Both executables report Go 1.27.3 and
  `CGO_ENABLED=0`.
- A manual upgrade check used a temporary instance and a real interactive shell. A
  v0.0.2 build started a Shell session and sent a message with Send. The 0.0.3
  `server restart` then replaced that server.
- After the upgrade, the recorded events and the session record were unchanged. The
  session address, tab title, recorded output, and **Sent messages** entry were
  correct. An old `/#<id>` address opened the home page.
- Publication requires tests and native release smoke checks on both Apple Silicon and
  Intel runners. The Intel executable was not run locally. This release does not claim
  a new end-to-end run with a real agent CLI.
