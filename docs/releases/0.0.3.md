BonBon 0.0.3 adds a simple update command:

```sh
bonbon update
```

It installs the latest macOS release at the executable's current location. Already
current or newer installations are left alone. Downloads use the same checksum
and version verification as the initial installer, with no GitHub CLI dependency.

Running servers and sessions continue. Run `bonbon server restart` when ready to
use the new version; restarting ends active sessions.

## Install

```sh
curl -fsSL https://github.com/gyson/bonbon/releases/latest/download/install.sh | sh
```

Existing v0.0.1 and v0.0.2 installations need the installer once to get the new
`update` command.

## Scope and validation

- macOS Apple Silicon and Intel. Development builds cannot self-update.
- Updates preserve invocation symlinks and replace their `bonbon` target. Renamed
  executables are rejected. The installation directory must be writable.
- No background checks, automatic restarts, or history changes.
- Installer fixtures cover update location, symlink invocation, current/newer
  version skips, checksum failures, and atomic replacement.
- Release publication requires the full checks and native release smoke checks
  on both Apple Silicon and Intel runners.
