BonBon 0.0.1 is a local web workspace for agent CLI tools on macOS. It includes
server-owned terminal sessions, durable SQLite history, persistent message drafts, file
references, and a menu bar with Open UI and Quit BonBon.

This release came before automatic database migrations. Current builds preserve
supported databases. See [database upgrades](../../README.md#database-upgrades).

## Included

- Start an interactive shell in a chosen workspace and run your agent normally.
- Close or switch browser views while the session and recording continue.
- Share a live session across tabs, with one explicit controller for input and size.
- Reopen live sessions or read the saved terminal screen after a session ends.
- Compose multiline messages, save drafts, and attach files as local path references.
- Query recorded history with read-only SQL through `bonbon query`.
- Install and update with curl and built-in macOS tools. GitHub CLI is not required.

## Install

Install with one command:

```sh
curl -fsSL https://github.com/gyson/bonbon/releases/latest/download/install.sh | sh
```

The installer selects Apple Silicon or Intel. It verifies the archive's SHA-256 and
checks the executable version. It installs to `~/.local/bin`. If needed, add that
directory to your PATH. To select another location, pass an absolute installer `--dir`.
The executable includes its web UI and requires neither Go nor Node.js.

```sh
bonbon --version
bonbon server start
bonbon ui
```

## Updates

```sh
bonbon update
```

The command verifies and replaces the invoked executable. The command keeps current or
newer installations. It does not restart a server or change saved history. When ready,
run `bonbon server restart`. This ends active sessions. `bonbon --version` reports the
executable, not the version of an already running server.

## Scope and limits

- macOS archives for Apple Silicon (`arm64`) and Intel (`amd64`), plus `install.sh` and
  `checksums.txt`. Linux and Windows packages are not included.
- Built with Go 1.27.1 and `CGO_ENABLED=0`. Archives include the MIT license and
  dependency notices. The standalone executable also retains these notices.
- Production data stays in `~/.bonbon`, separate from development data in
  `~/.bonbon-dev`. This release uses SQLite format 3 and protocol `bonbon/11`.
- There is no background update check, automatic update, or Homebrew package.
- Binaries are not Apple Developer ID signed or notarized.
- The server listens on loopback without authentication. Do not expose it to a network
  or use it as a security boundary between local users. Terminal input, output, drafts,
  and attachments may contain secrets. BonBon stores them without redaction.
- Recordings preserve terminal evidence. Native agent resume, imports, forks, managed
  worktrees, and backup/restore are not implemented.

## Validation

- `make build`, `make test`, `make check`, and `make web-check` passed locally.
- Installer fixtures checked both architecture selections, pinned versions, numeric
  update comparisons, checksum and authentication failures, and atomic replacement.
- A compiled release smoke check on Apple Silicon verified the version and HTTP delivery
  of the embedded UI. It also verified a read-only SQL query and clean server shutdown.
- Both architecture archives and SHA-256 checksums were verified, including the embedded
  and packaged license notices. The release binary passed `govulncheck`.
- The publishing workflow requires native tests and release smoke checks on both Apple
  Silicon and Intel. This release does not claim a new manual agent UI run.
